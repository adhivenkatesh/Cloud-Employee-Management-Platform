# Cloud Employee Management Platform (CEMP)

## Overview

Cloud Employee Management Platform (CEMP) is an enterprise cloud-native application built as a hands-on learning project using modern DevOps and Cloud technologies.

The goal of this project is to demonstrate an end-to-end software delivery lifecycle from development to deployment on Kubernetes.

---

## Technologies

- ASP.NET Core Web API
- Docker
- Kubernetes
- ConfigMaps
- Secrets
- Services
- Ingress
- Helm
- Azure Kubernetes Service (AKS)
- Terraform
- GitHub
- Azure DevOps (Upcoming)
